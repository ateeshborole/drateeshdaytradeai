# drateeshdaytradeai

My day-trading skills for Claude Code on the web. Every cloud session started
from this repo loads them from `.claude/skills/`: `/trader-scanner`,
`/trader-news`, `/trader-entry`, `/trader-exit`, `/trader-timemachine`,
`/trader-budget`, `/trader-risk`, `/trader-broker`, `/trader-alerts`,
`/trader-analyst`, `/trader-pelosi`.

Copied from [Jakeschincariol/day-trader-skill](https://github.com/Jakeschincariol/day-trader-skill)
(MIT license, see `LICENSE`).

Not financial advice. Paper trading by default; no order goes through without your yes.
